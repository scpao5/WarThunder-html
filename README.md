# 战争雷霆 网页版

> 一个基于 Three.js 的**单文件离线**坦克/战机/直升机战斗模拟器。
> 纯前端,无后端、无外部请求、断网可玩。

---

## 📖 项目简介

| 项 | 说明 |
|---|---|
| **形态** | **单个 HTML 文件**(`index.html`),2.8 MB,内联引擎 + 音频 |
| **引擎** | Three.js r128(已内联,无需外网) |
| **运行** | 浏览器直接打开,或手机"添加到主屏幕" |
| **依赖** | **零** —— 不联网、不装东西、不开服务器 |
| **协议** | GPLv3 |

### 特色机制

- **俄联邦永不后退** —— T-90A / BMPT / T-72B3A 倒车只有 **5 km/h**(真实数据)
- **ERA 爆炸反应装甲** —— 独立血条,先吃伤害,溢出才伤车体
- **多管齐射** —— 猎豹双管、石勒喀四管、BMPT 双管,**同时开火**
- **炮火打击** —— 天降火箭弹,带完整**中文乘员播报**(请求→坐标→收到→开火)
- **苏-25 攻击机** / **武直** —— 点飞机按钮 **50% 随机**;武直用真实直升机物理(总距/悬停/倾斜转弯)
- **AI 友军** —— 5 台随机车型,会占点、会开火
- **占点积分** —— 双方 100 分,完全占领才扣分
- **T58 重型坦克** —— 击杀 8 个后 BOSS 出场
- **烟雾弹** —— 封烟后敌人在烟里看不见你

### 音效 & UI

- **真·战争雷霆音效** —— 各口径炮声、导弹、引擎、爆炸均为游戏原生音频
- **中文乘员播报** —— 夺点、击毁、修理、装填、炮火呼叫
- **真·战争雷霆 UI 图标** —— 全部按钮用游戏内 SVG 矢量图标
- **战果提示** —— 银狮 + 经验(真图标)

## 玩法

### 移动端

| 操作 | 功能 |
|---|---|
| 左下**摇杆** | 移动 / 转向 |
| 右侧**滑动** | 瞄准(转动视角) |
| **开火** | 主炮 / 机炮 |
| **导弹** | 发射导弹 / 火箭弹 |
| **望远镜** | 开镜(狙击视角) |
| **烟雾** | 释放烟幕 |
| **工具箱** | 修理(10 秒,期间不能动) |
| **炮火打击** | 呼叫天降火箭弹(冷却 60 秒) |
| **飞机** | 呼叫空中支援(**击杀 5 个解锁**,随机 苏-25 / 武直) |
| **脱离卡死** | 卡住时传送脱困(冷却 15 秒) |

### 电脑

`W/A/S/D` 移动,`鼠标` 瞄准,`左键` 开火,`右键` 导弹,`V` 呼飞机,`ESC` 设置

### 胜负

- 全歼敌军 → **胜利**
- 复活次数(2 次)耗尽 / 占点分归零 → **失败**
